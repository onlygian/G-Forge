## Context

**Decision (original, retained):** rebrand to **G-Proof** (Gianmarco's shipping standard for Claude Code). The G-Factor is the human in the loop; the gate enforces discipline before merge. Tagline: **"Claude Code is powerful. It's also optimized for velocity, not reliability. But you can G-Proof it."** — positioning around governance layer (educated, enforced project management), not another agent orchestrator.

By the time this milestone runs, M41's `/g-release` + `/g-changelog` + `/g-doctor` version-consistency machinery are long-shipped — this release is cut *through* them, and the README status strip (maintained since v2.3.0) carries over restyled.
